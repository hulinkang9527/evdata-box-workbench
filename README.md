## 作品概述

基于 EVData 上海市新能源汽车（嘉定）数据创新实验室发布的 **EVData Box 首批 5 个教研数据集**，设计并实现的个性化数据集管理与展示工作台，围绕赛题「高效数据管理、展示和探查」三大目标提供六项能力：

| 能力 | 说明 |
|---|---|
| 数据目录管理 | 5 个教研数据集统一登记元数据（版本、机构、时间跨度、规模、格式、分区策略、敏感等级、引用格式），构成「入门 → 进阶 → 综合」的完整教研链路 |
| 数据字典检索 | 3 套官方数据字典 Excel 已结构化解析为可在线检索的字段表（按表筛选、关键词搜索、点击排序、分页浏览），字段敏感等级 L1/L2/L3 以徽标可视化 |
| 样本数据预览 | 各数据集真实样本数据免下载在线预览，支持搜索、排序、分页 |
| 数据探查可视化 | 30+ 张交互式 ECharts 图表，**全部基于本地数据文件用 Python 实测统计计算**：SOC/车速/电压/电流分布、充电状态构成、电池单体电压与压差分布、空间散点、24 小时行为节律、数据治理前后对比等 |
| 数据质量检测报告 | 参照 GB/T 36344-2018 五维评价体系（完整性/规范性/准确性/一致性/时效性）输出质量雷达图，附检测项明细与 GB/T 32960 异常码规则库 |
| 数据手册在线阅读 | 5 份官方数据手册（Datasheet）全文内置，Markdown 在线渲染 |

## 五个数据集

| # | 数据集 | 时间跨度 | 正式版规模 | 格式 | 教学定位 |
|---|---|---|---|---|---|
| ① | 国标32960入门数据集 | 1 个月 | 约 161 万行 / 26.26 MB | PARQUET | 入门：国标认知与数据质量检测 |
| ② | 新能源汽车多车辆运行数据集 | 2 周 | 约 4,100 万行 / 760 MB | PARQUET | 进阶：群体行为与空间分析 |
| ③ | 新能源汽车长周期运行数据集 | 1 年 | 约 3,600 万行 / 580 MB | PARQUET | 进阶：三电深度诊断与电池衰减 |
| ④ | 新能源汽车车型信息数据集 | 2019—2026 | 200 行 | Excel | 入门：数据治理与车型研究 |
| ⑤ | 新能源汽车停留与充电行为数据集 | 1 个月 | 约 4.1 万条 / 约 7,300 辆车 | Excel | 综合：业务分析与商业决策建模 |

合计 13 张数据表、正式版约 7,869 万行记录。工作台内的统计图表基于本地 DEMO 样例数据实测（已在页面标注「DEMO 实测」口径），数据集规模、时间范围等元数据采用官方数据手册口径，两者严格区分。

## 使用方式

1. **在线**：打开 <https://hulinkang9527.github.io/evdata-box-workbench/>
2. **离线**：下载仓库 → 进入目录 → 双击 `index.html`（Chrome / Edge 等现代浏览器）
3. 首屏为品牌着陆页，点击「进入工作台」进入主应用（也可直接打开 `app.html` 跳过着陆页）
4. 左侧导航切换「总览看板 / 5 个数据集 / 数据探查中心 / 案例参考 / 关于与使用说明」
5. 数据集详情内通过页签使用「概述与元数据 / 数据字典 / 数据预览 / 数据探查 / 质量报告 / 数据手册」

> 请保持目录结构完整（index.html、app.html、assets、data、jsdata、handbooks 缺一不可）。

## 技术实现

- **数据探查与统计**：Python 3 + pandas + pyarrow + openpyxl，解析 PARQUET / CSV / XLSX 三类格式
- **可视化**：Apache ECharts 5.5.1（本地化内置，零外网依赖）
- **前端**：原生 HTML / CSS / JS 零依赖 SPA，哈希路由 + 自研 GFM 表格级 Markdown 渲染器
- **离线工程**：统计数据不通过 fetch 加载（`file://` 下浏览器禁止 fetch 本地文件），而是预计算后包装为 JS 数据资产（`window.DATA_XXX`），由 script 标签直接加载

## 数据来源与合规

- 数据来源：EVData 上海市新能源汽车（嘉定）数据创新实验室 · 数据开放平台 EVData Box 教研数据集
- 车辆 ID、车型代码已由数据提供方脱敏（随机编码，不可逆推）；日期已偏移处理；数据集不含手机号、身份证号、车牌号等个人敏感信息
- 本作品仅用于 X-GAME 2026 天华学院校内赛教学竞赛场景，不对外分发原始数据；空间分析保持在群体/区域聚合层面，不输出单车可识别轨迹明细
